OrgSuite Meta Developers

Companion site for creating a Meta app the official way. This deploy is not a Meta App ID. App Review and Business Verification still need the owner Facebook login.

Completed here

  • Public GitHub repo with MIT license
  • Privacy policy URL for App Review
  • App Review owner checklist
  • Links to existing certificate guidance repos

Requires Authorization

  • Facebook account + Meta developer registration
  • Create app at developers.facebook.com/apps/creation
  • Business Verification
  • Advanced Access App Review

Owner checklist

  1. Open Meta developer registration while logged into Facebook.
  2. Create the app at apps/creation. Use case: own business first (Standard Access) unless this must serve other businesses.
  3. Privacy Policy URL: /privacy.html on this site.
  4. Store App ID in Vercel env as META_APP_ID. Store App Secret as META_APP_SECRET only in Vercel — never in GitHub.
  5. Log one successful Graph API call per permission before requesting Advanced Access.
  6. Submit App Review only after recordings and Business Verification are ready.
