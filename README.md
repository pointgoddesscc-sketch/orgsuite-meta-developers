# OrgSuite Meta Developers

Public companion for Meta for Developers work in OrgSuite / PSE Management.

**This repository does not create a Meta App ID.** Creating the app, Business Verification, and App Review require the owner Facebook login at [developers.facebook.com](https://developers.facebook.com).
