Privacy Policy

Effective 31 August 2026. Operator: Point Goddess CC / PSE Management.

This page describes how the OrgSuite Meta Developers companion site handles information. It is published so a future Meta app can show a public privacy policy URL during App Review.

What this site collects

This static site does not require an account and does not collect Facebook profile data, messages, or payment details. Server logs from Vercel may include standard request metadata such as IP address, user agent, and path.

If a Meta app is connected later

If the owner authorizes a Meta app for OrgSuite, only the data needed for the approved use case will be requested. That data will be used to operate workplace tools (for example WhatsApp Cloud API or Facebook Login for the owner’s own business). It will not be sold.

Sharing

Platform data from Meta is not shared with unrelated third parties. Hosting is on Vercel. Source is on GitHub under the MIT license.

Deletion and contact

To request deletion of workplace data tied to an authorized Meta integration, contact pointgoddesscc@gmail.com.
